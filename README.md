# Portfolio Manager

Standalone executable for managing your Python portfolio projects (URL Shortener, GraphQL Blog, etc.) with Cloudflare Tunnel integration.

## Download

Get the latest release from the [Releases tab](https://github.com/voicenotesite/PortfolioManager/releases).

## Usage

### Linux
1. Make executable: `chmod +x PortfolioManager`
2. Run: `./PortfolioManager`

### Windows
Just double-click the `.exe` file.

### macOS
1. Make executable: `chmod +x PortfolioManager`
2. Run: `./PortfolioManager`

## Features
- Start/stop backend servers with one click
- Manage Cloudflare tunnels
- Real-time server logs display
- Health monitoring with status indicators
- Cross-platform (Linux, Windows, macOS)

## Projects Managed
- URL Shortener (fastapiurl)
- GraphQL Blog (graphql-blog)
- Portfolio API (python-portfolio - unified backend)
